\# CodeAlpha Task 2: Phishing Awareness Training



\## Project Overview

This project is an interactive educational website designed to help users recognize phishing attempts and practice safe online behavior.



\## Features

\- Introduction to phishing and its common types

\- Common warning signs of suspicious messages

\- Fictional phishing email example with red flags

\- Cybersecurity prevention tips

\- Interactive quiz with five questions, instant feedback, and scoring

\- Responsive design for different screen sizes



\## Technologies Used

\- HTML5

\- CSS3

\- JavaScript

\- Microsoft Edge for testing



\## How to Run

1\. Download or clone this repository.

2\. Open `index.html` in a web browser.

3\. Read the training material and complete the quiz.



No server or additional software is required to run this website.



\## Learning Outcomes

This project helped me practice creating a basic educational website, applying CSS styling, using JavaScript for interactive quizzes, and communicating cybersecurity awareness concepts.



\## Safety

This website is for educational purposes. It uses a fictional email example and does not collect passwords or personal information.
